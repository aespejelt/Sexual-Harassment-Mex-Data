# Sexual-Harassment-Mex-Data
Data for the study of street sexual harassment. 
##########################
This database was established by Dr. Angelina Espejel for the study of street sexual harassment. For any questions regarding the dataset or to request permission for its use, please send an email to: angelina.et@gmail.com.
The purpose of using this database is purely academic. 
This data set is registered as intellectual propertyin INDAUTOR with the number:  03-2022-120712052700-01. ##################################

This dataset gathers reports fomr victims of sexual harassment in México and Querétaro city. Collected from social network X and Siempre Seguras APP (Android & OS) to investigate street sexual harassment.

The publication of the results are in: 

Ortiz-Espinoza y Trujillo es: Ortiz-Espinoza, Á., & Trujillo, A. E. (2024). Siempre seguras: Observatorio de acoso sexual callejero basado en inteligencia artificial. Regiones y Desarrollo Sustentable, 24(45). https://doi.org/10.63042/vtw2jd86.
